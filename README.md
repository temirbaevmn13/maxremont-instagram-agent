# MAX REMONT — Instagram AI Agent

Бесплатный проект генерации контента для @maxremontbishkek. Автоматическая публикация по умолчанию выключена (`PUBLISH_ENABLED=false`).

Для запуска необходимо загрузить файлы из архива проекта в корень репозитория: `run.py`, `agent.py`, `render.py`, `publish.py`, `state.py`, `config.json`, `topics.json`, `requirements.txt`, `assets/README.md`, `state/.gitkeep` и `.env.example`.

После загрузки перейдите Actions → MAX REMONT — Instagram без рекламы → Run workflow. Черновики появятся в Artifacts.
