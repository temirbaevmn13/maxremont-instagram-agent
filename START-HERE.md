# Первые 10 минут — MAX REMONT BISHKEK

**Аккаунт:** https://www.instagram.com/maxremontbishkek/  
**Цель:** автоматические Reels, Stories, посты; **без платной рекламы**.

## Уже подготовлено
- 27 тем о ремонте и отделке помещений.
- Фирменные изображения и 15-секундные Reels из текстовых карточек.
- Пробный режим: публикации выключены.
- Расписание (Бишкек): **12:00 Stories**, **16:00 посты (Вт/Чт/Сб)**, **19:00 Reels**.
- Бесплатный Gemini API — необязательный; если ключа нет, используются готовые темы.

## Твои действия — сначала только 2
1. Создай **новый публичный репозиторий** `maxremont-instagram-agent` в GitHub и загрузи туда содержимое архива. Не путай с уже существующим репозиторием сайта.
2. GitHub → репозиторий → **Actions** → **MAX REMONT — Instagram без рекламы** → **Run workflow**, выбор `all`. Дождись завершения, скачай **Artifacts → maxremont-content-...**. Получишь ролик, Story, пост и текст.

Все файлы — **черновики**. Пока ничего не публикуется. Когда проверишь качество, подключим официальные Meta API и Cloudinary и установим `PUBLISH_ENABLED=true`. Не присылай пароль и API-ключи в чат.

## Потом для ИИ-текстов
1. Создай бесплатный API-ключ на https://aistudio.google.com/ (если твоему аккаунту доступен бесплатный лимит).
2. В GitHub → **Settings → Secrets and variables → Actions → New repository secret** добавь `GEMINI_API_KEY`.
3. Снова запусти workflow. После выполнения проверь `content.json`: `source=gemini` означает, что текст создан ИИ; `source=templates` означает, что сработали подготовленные темы.

## Для автоматической публикации (позже)
Включаем Business-аккаунт Instagram, связываем Facebook Page, создаём Meta App и выдаём публикационные разрешения. Задаём секреты `META_ACCESS_TOKEN`, `IG_USER_ID`, `CLOUDINARY_URL`. Затем **после успешного теста** задаём переменную `PUBLISH_ENABLED=true`.

**Ограничения:** GitHub Actions может запаздывать; генерация видео здесь — типографические карточки, не реалистичные ИИ-съёмки. Для рекламы никаких скриптов и бюджетов нет. Приложение Meta и токены требуют настройки/обслуживания.
